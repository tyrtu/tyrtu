### 🍽️ TableKey — *2026*

[GitHub](https://github.com/tyrtu/TableKey) · [Live App](https://table-key.vercel.app/)

<p align="center">
  <img src="./demo/tablekey/customer_panel.png" height="320" style="max-height:320px;width:auto;object-fit:contain;" alt="TableKey customer mobile interface — menu and order flow"/>
  &nbsp;&nbsp;&nbsp;
  <img src="./demo/tablekey/waiter_panel.png" height="320" style="max-height:320px;width:auto;object-fit:contain;" alt="TableKey waiter panel — table and request management"/>
</p>

Paper menus and verbal orders break down at scale and leave no audit trail. TableKey replaces the entire flow — customers scan a QR code at their table, place orders, and track status in real time, while waiters, kitchen staff, and managers each get a role-specific workspace. The hardest call was billing: rather than trusting the client, all payment calculations run as server-side Supabase RPCs under RLS so the bill can't be tampered with before it's settled.

- QR-based ordering with no app installation required
- Waiter-approval gate before a table can place orders
- Real-time order tracking from placement through to serving
- Kitchen display system with explicit status workflow
- Manager dashboard covering menus, staff, analytics, and reconciliation
- Cash, Stripe, and M-Pesa payment integrations
- Tamper-proof billing via server-side RPCs and Row Level Security

`React` `TypeScript` `Vite` `Tailwind CSS` `Zustand` `Supabase` `PostgreSQL` `Realtime`

### 📈 APEX Trading Lab — *2026*

[GitHub](https://github.com/suhark/APEX) · [Live App](https://apextradinglab.app/)

<p align="center">
<img src="./demo/apex/apex-screenshot.png" width="90%" alt="APEX Trading Lab terminal showing tick charts and bot controls"/>
</p>

Retail traders on Deriv lose sessions fast because there's no built-in circuit breaker. APEX adds a configurable session loss guardrail that stops all bots automatically when the threshold is hit, sitting on top of a full algorithmic execution terminal with live tick charts and multi-signal strategies.

- Manual terminal with tick charts and Rise/Fall contracts
- Algorithmic bots, Signal AI, and multi-signal strategies
- Session loss guardrail that halts all bots automatically
- Account context isolation and multi-step live trading arming

`React` `TypeScript` `Vite` `Supabase` `Deriv API`

### 🏡 Karibu Stay — *2026*

[GitHub](https://github.com/tyrtu/Karibu-Stay) · [Live App](https://karibu-stay-puce.vercel.app/)

<p align="center">
  <img src="./demo/karibu-stay/guest_panel.png" height="400" style="max-height:400px;width:auto;object-fit:contain;" alt="Karibu Stay guest discovery view with map and listing cards"/>
  &nbsp;&nbsp;&nbsp;
  <img src="./demo/karibu-stay/host_panel.png" height="400" style="max-height:400px;width:auto;object-fit:contain;" alt="Karibu Stay host dashboard showing bookings and listing management"/>
  &nbsp;&nbsp;&nbsp;
  <img src="./demo/karibu-stay/listing_view.png" height="400" style="max-height:400px;width:auto;object-fit:contain;" alt="Karibu Stay listing detail page with price breakdown and booking form"/>
</p>

Africa On The Move 2027 will fill stadiums across the continent, but short-term accommodation near those venues is fragmented and hard to discover. Karibu Stay is a marketplace purpose-built for that context — guests filter by tournament venue and book directly, hosts list and manage properties. The key security decision was routing all booking writes through an Edge Function so RLS policies are enforced server-side and no client can bypass them.

- Interactive Mapbox map with price-label pins that fly to the selected venue
- Listings filterable by venue, price, property type, and guest count
- Favourites synced to account with local storage fallback before sign-in
- Booking flow with date validation and live price breakdown
- Post-stay guest reviews after host marks stay complete
- Host dashboard for listing creation, editing, publishing, and photo uploads
- All booking writes routed through a Supabase Edge Function under RLS

`React` `TypeScript` `Vite` `Tailwind CSS` `Mapbox GL JS` `Supabase` `PostgreSQL` `Edge Functions`
